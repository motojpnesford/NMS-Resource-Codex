# NMS-Resource-Codex

“Explore. Refine. Discover.”

（探索し、精製し、発見する。）

概要

NMS Resource Codex は、No Man’s Sky の資源・素材・精製・クラフト情報を検索・参照できるオフライン対応の資源図鑑アプリです。

本プロジェクトは、単なる検索データベースではなく、資源同士の関連性をたどりながら探索できる「インタラクティブ資源図鑑」を目指しています。

⸻

開発目標

* 資源名検索（完全一致・部分一致）
* 検索候補（予測変換）
* 資源詳細表示
* 精製レシピ表示
* 入手方法・用途表示
* 逆引き検索（この素材を使うアイテム一覧）
* 関連資源へのクリック移動
* アイコン表示
* クラフトツリー表示（将来実装予定）

⸻

コンセプト

「検索するデータベース」ではなく、

素材をたどりながら知識を広げられる資源図鑑

を目指します。

⸻

開発方針

Ver.1で得た経験を活かし、Ver.2では設計を最初に固めてから開発を進めます。

* JSON構造を統一する
* 資源をIDで管理する
* 機能を実装してからデータを大量入力する
* 将来の拡張性を重視する
